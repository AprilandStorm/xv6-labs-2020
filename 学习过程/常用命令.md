# 常用命令
- 运行并构建xv6 `make qemu`
- 退出xv6 `ctrl+a 再按x`
- 测试是否完成 `make grade`
- cd 表示更改目录
1. 切换到指定目录 `cd/path/to/directory`
2. 切换到用户的home目录 `cd`
3. 返回上一层目录 `cd..`
4. 切换上次所在目录 `cd_`
5. 使用相对路径 `cd subdirectory`
6. 使用绝对路径 `cd/home/username/documents`
- cat 代表“连接”，主要用于显示文件内容或者创建文件
1. 显示文件内容 `cat filename.txt`
2. 将多个文件合并显示 `cat file1.txt file2.txt`
3. 将文件内容写入新文件 `cat file1.txt > newfile.txt`
4. 追加内容到文件末尾 `cat file2.txt >> file1.txt`
5. 显示带行号的文件内容 `cat -n filename.txt`
6. 连接多个文件并输出 `cat file1.txt file2.txt > combined.txt`
