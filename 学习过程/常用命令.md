# 常用命令
- 运行并构建xv6 `make qemu`
- 退出xv6 `ctrl+a 再按x`
- 测试是否完成 `make grade`
- cd 表示更改目录
1. 切换到指定目录 `cd/path/to/directory`
2. 切换到用户的home目录 `cd`
3. 返回上一层目录 `cd..`
4. 切换上次所在目录 `cd_`
5. 使用相对路径 `cd subdirectory`
6. 使用绝对路径 `cd/home/username/documents`
- cat 代表“连接”，主要用于显示文件内容或者创建文件
1. 显示文件内容 `cat filename.txt`
2. 将多个文件合并显示 `cat file1.txt file2.txt`
3. 将文件内容写入新文件 `cat file1.txt > newfile.txt`
4. 追加内容到文件末尾 `cat file2.txt >> file1.txt`
5. 显示带行号的文件内容 `cat -n filename.txt` -n：表示为每一行加上行号
6. 连接多个文件并输出 `cat file1.txt file2.txt > combined.txt`
- ls 输出当前目录的文件列表
- 查看内存使用 `free -h`
- 卸载软件包 `sudo apt remove 软件名`
- 列出大软件包 `dpkg-query -Wf '${Installed-Size}\t${Package}\n' | sort -n | tail -n 20
`
- 卸载并清理配置 `sudo apt purge 软件名`
- 自动清理系统 `sudo apt autoremove && apt clean`
- 将echo的输出送到文件out中 `echo hello > out`
- 将out文件输出 `cat < out`
- 创建新目录 `mkdir`
- git 是一个分布式版本控制系统（DVCS），用于跟踪文件的变化、协调多人协作开发、管理代码历史。常见用途如下：
1. 初始化一个新的git仓库（在当前目录下创建`.git`） `git init`
2. 克隆远程仓库到本地 `git clone <url>`
3. 将文件加入暂存区 `git add <file>`
4. 提交暂存区的更改，并附带提交说明 `git commit -m "msg"`
5. 参看当前工作目录和暂存区的状态 `git status`
6. 查看提交历史 `git log`
7. 推送提交到远程仓库 `git push`
8. 从远程仓库拉取并合并最新代码 `git pull`
9. 显示分支或创建分支 `git branch`
10. 切换到某个分支 `git checkout <branch>`
