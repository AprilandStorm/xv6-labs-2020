# 软件包安装、实验代码获取
## u-shell执行三个命令
```
sudo apt-get install git build-essential gdb-mltiarch qemu-system-misc gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu
sudo apt-get remove qemu-system-misc
sudo apt-get install qemu-system-misc=1:4.2-3ubuntu6
```
第一条命令是开发和调试RISC-V架构的程序必要的工具和环境，第二个为卸载旧版软件包，第三个为安装指定版本的qemu虚拟化工具的misc系统仿真部分

## 将实验代码提交到github[基础操作](https://xv6.dgs.zone/labs/use_git/git1.html)
- 创建测试分支
```
git checkout util         # 切换到util分支
git checkout -b util_test # 建立并切换到util的测试分支
```
- 提交
```
git add .
git commit -m "完成了第一个作业"
git checkout util
git merge util_test
git push github util:util
```
- 重命名分支 util_test → new_name：如果你当前就在这个分支上，执行：`git branch -m new_name`
；如果你当前不在该分支：`git branch -m util_test util
`\

- 这里采用的是配置SSH，实现虚拟机和github库的链接，具体方法为：\
1.检查是否已有 SSH key（可跳过）打开终端，输入：`ls ~/.ssh
`看看是否有 id_rsa 和 id_rsa.pub 文件；如果有，可以跳过“生成 SSH 密钥”这一步；如果没有，就执行下面的步骤生成\
2.生成 SSH 密钥，输入`ssh-keygen -t rsa -b 4096 -C "你的 GitHub 邮箱"`；提示 Enter file in which to save the key，直接按回车，使用默认路径 ~/.ssh/id_rsa；提示输入密码，可以留空，直接回车\
3.添加 SSH 公钥到 GitHub，执行`cat ~/.ssh/id_rsa.pub`；复制输出的整行内容（以 ssh-rsa ... 开头），然后登录 https://github.com;点击右上角头像 → Settings；左边栏点击 SSH and GPG keys；点击右上角 New SSH key；Title：随便填，比如 “ubuntu虚拟机”，Key：粘贴刚才复制的公钥；点击 Add SSH key\
4.修改远程仓库地址为 SSH，在命令行执行
```
cd ~/xv6-labs-2020
git remote set-url github git@github.com:AprilandStorm/xv6-labs-2020.git
```
测试连接：`ssh -T git@github.com`;当看到`Hi AprilandStorm! You've successfully authenticated, but GitHub does not provide shell access.`时说明SSH配置成功
