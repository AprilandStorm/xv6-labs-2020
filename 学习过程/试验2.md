```

```
# 实验
## System call tracing
- 实现trace功能，跟踪用户程序中调用的系统调用，并将调用的相关信息打印出来
- user/trace.c代码
```
#include "kernel/param.h"
#include "kernel/types.h"
#include "kernel/stat.h"
#include "user/user.h"

int
main(int argc, char *argv[])
{
  int i;
  char *nargv[MAXARG];//nargv[] 是一个新的参数数组，用来保存将要执行的命令和参数（从 argv[2] 开始复制）;MAXARG 是一个宏，应该在其他地方定义，比如定义为 32 或 64，表示最大参数个数。
   //argc < 3: 参数太少;(argv[1][0] < '0' || argv[1][0] > '9')：第一个参数不是数字开头，可能不是合法的 mask;如果不满足条件：输出错误信息
  if(argc < 3 || (argv[1][0] < '0' || argv[1][0] > '9')){
    fprintf(2, "Usage: %s mask command\n", argv[0]);
    exit(1);
  }
  //argv[1] 是字符串，比如 "5"，调用 atoi 转为整数 5;trace(5)：这是一个自定义系统调用，功能是设置系统调用追踪的掩码（mask）;类似 xv6 的 trace() 系统调用，掩码用于控制要追踪哪些系统调用;如果失败，输出错误，退出
  if (trace(atoi(argv[1])) < 0) {
    fprintf(2, "%s: trace failed\n", argv[0]);
    exit(1);
  }
  //把命令和参数（从 argv[2] 开始）复制到 nargv[0], nargv[1], …中
  for(i = 2; i < argc && i < MAXARG; i++){
    nargv[i-2] = argv[i];
  }
  //exec()：系统调用，用于用另一个程序替换当前进程;nargv[0] 是程序名，如 "ls";nargv 是参数数组，以 NULL 结尾（此处应依赖实现自动结束）;如果 exec() 成功，当前进程就会被 "ls" 进程替代，不会再往下执行;如果 exec() 失败，继续执行 exit(0);，虽然一般不会执行到
  exec(nargv[0], nargv);
  exit(0);
}
```
- 例子1
```
$ trace 32 grep hello README
3 : syscall read -> 1023
3 : syscall read -> 966
3 : syscall read -> 70
3 : syscall read -> 0
```
trace 32表示启用了跟踪功能，32表示跟踪系统调用号掩码为5的系统调用（1<<5 =32）；在kernel/syscall.h中，`#define SYS_read  5`,所以要跟踪read系统调用；然后执行`grep hello README`命令，即用grep搜索README文件中的hello\
打印输出行，3表示运行grep的进程ID，syscall read表示发生了read系统调用，-> 1023表示调用read的返回值，这里表示读取了1023字节\
- 例子2
```
$ trace 2147483647 grep hello README
```
2147483647的低31位为1，表示跟踪所有系统调用
